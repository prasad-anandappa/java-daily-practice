# Day 012 — Word Ladder II

**Problem.** Given `beginWord`, `endWord` and a word list, return ALL shortest transformation sequences from `beginWord` to `endWord`, where consecutive words differ by exactly one letter and every word after the first is in the list. (LeetCode 126, Hard.)

**Approach.** BFS level by level from `beginWord`, recording for each discovered word not one parent but *every* parent that reaches it on the earliest possible level. Those edges form a DAG layered by BFS distance; a DFS from `endWord` back to `beginWord` along the parent edges enumerates exactly the shortest ladders — every path it can follow has BFS-shortest length by construction, and every shortest ladder is present because a word only ever points to words one level closer to the start. The load-bearing detail is *when* words are marked visited: a word found on level k can have several level-k parents, all legitimate, so removal from the unvisited set happens only after the whole level is processed. Removing on first sight (the usual BFS reflex) silently drops ladders; removing a level later admits longer cyclic paths. Neighbours are generated by mutating each position through 'a'..'z'. `main` cross-checks against two independent oracles: a plain BFS that computes only the shortest length, and a bounded brute-force DFS enumerating every simple path of exactly that length — plus direct validation of every returned ladder (endpoints, one-letter steps, dictionary membership) and a 300-case fuzz over random small dictionaries.

**Complexity.** BFS costs O(N · L · 26) candidate generations for N dictionary words of length L (each checked against a hash set in O(L)). The enumeration phase is output-sensitive: its work is proportional to the total size of all shortest ladders, which can be exponential in pathological dictionaries — unavoidable, since that is the size of the answer. Space O(N · L) for the parent DAG plus the output.

**Takeaways.**
- "Find one shortest path" and "find ALL shortest paths" differ by exactly one decision: single-parent + visit-on-discovery versus parent-DAG + visit-on-level-completion. Most wrong Word Ladder II solutions are Word Ladder I solutions with a list added.
- BFS layering is a proof, not just a traversal: once edges only ever connect consecutive layers, any root-to-leaf walk in the parent DAG is automatically a shortest path — the enumeration needs no length checks of its own.
- When the output can be exponentially large, correctness arguments shift to the structure (the DAG contains all and only shortest prefixes) — the brute-force oracle is only feasible because the fuzz dictionaries are kept tiny on purpose.
